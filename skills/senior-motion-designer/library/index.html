    Visual directions

    Three directions, never a template.

    The reference frames behind the library's three visual directions. Clients no longer pick one: the skill decides each film's direction from the business, the script and the brand, starts from the direction that fits (or sets a new one) and adapts it. It views that direction's contact sheet to calibrate the feel, never as a template.

    Reference only. Client videos never reuse these frames' products, data, people, headlines or layouts. The frames show a look; the client supplies everything in it.

    Minimal User Interface Style

    The client's own product interface is the hero: rebuilt interface cards on a near-white canvas beside a bold two-color headline.

    • Flat, straight-on cards with large radii and very soft shadows.
    • Black, one accent color and its tints; pale halo circles, a thin line circle and a small spark mark.
    • The interface does the moving: counters, charts, toggles, a cursor.
    • The references share one split layout; client films don't.

    Minimal Single Visual Style

    One idea per scene, acted out by one calm abstract form, with a short statement in bold type.

    • Frosted glass shapes on a bright studio floor with soft reflections.
    • A change from start to finish: pale and many, then one saturated shape.
    • The key word in the accent color; one accent, no second hue.
    • Slow, smooth transformations; one scene's final shape can start the next.
    Files styles/minimal-single-visual/sheet.jpg · 01.jpg – 10.jpg

    Minimal Gradient SaaS Style

    A soft, grainy multi-hue gradient, a gradient-filled headline, and frosted tiles, cables and app windows showing things flowing into one result.

    • Glass tiles, curved cables, a glowing hub and a tilted app window.
    • A palette of two or three neighboring hues built from the client's brand color.
    • The motion is flow: cables draw, pulses travel, the hub lights up, the window fills.
    • The references lean on one hub diagram; client films use it only when a line is about connecting.
